# Home title font

`pacifico-regular.ttf` is Pacifico Regular, bundled locally so the home title does
not rely on installed fonts or third-party requests at runtime.

- Project: https://github.com/googlefonts/Pacifico
- Download: https://fonts.gstatic.com/s/pacifico/v23/FwZY7-Qmy14u9lezJ96A.ttf
